# mariana-pinterest

Recriação **inspirada** na captura de tela enviada, feita com HTML, CSS e JavaScript puro.

## Executar no VS Code
1. Extraia `mariana-pinterest.zip` para a Área de Trabalho.
2. No VS Code, escolha **Arquivo → Abrir Pasta...** e selecione `mariana-pinterest`.
3. Abra `index.html`. Para atualizar automaticamente ao salvar, instale a extensão **Live Server** e clique em **Go Live**.

## Recursos implementados
- Layout responsivo com grade tipo masonry.
- Busca por título, descrição e tópico.
- Filtros de tópicos.
- Modal de detalhes dos Pins.
- Perfil acessível pelo avatar “M”, com abas para ver Pins salvos e Pins criados.
- Salvar/remover Pins usando `localStorage`; os salvos permanecem ao reabrir o navegador.
- Criar um Pin usando URL de imagem, título, descrição e tópico.
- Comentários temporários na prévia.
- Compartilhar/copiar informações do Pin quando o navegador permitir.
- Navegação lateral com estados demonstrativos.

## Notas
- As imagens de demonstração são carregadas de URLs do Unsplash; é necessária conexão com a internet para carregá-las.
- Algumas funções da plataforma real (conta, notificações reais, mensagens e recomendações personalizadas) são simuladas.
- Este projeto não é afiliado ao Pinterest e não copia seu backend ou código proprietário.
